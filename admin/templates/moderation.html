🔐 Права бота и ограничения ⌄

Для удаления сообщений бот должен быть администратором группы с правом «Удаление сообщений» (can_delete_messages). При отсутствии прав удаление не сработает и ошибка отобразится в счётчике.

Эта функция не удаляет системные баннеры в личном интерфейсе Telegram, включая «Ваша заявка на вступление в канал принята» — они не являются обычными сообщениями группы и Telegram Bot API не предоставляет боту способа их удалить.

Модерация работает только для новых сообщений, полученных ботом после включения. Старые записи и личные уведомления Telegram она не очищает.
